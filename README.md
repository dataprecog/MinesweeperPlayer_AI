MinesweeperPlayer_AI, is a program that solves a Minesweeper game using Symbolic Artificial Intelligence.

Symbolic AI is an approach to artificial intelligence that represents knowledge
explicitly using symbols—such as words, facts, rules, and logical
relationships—and then reasons over those representations.

For example, a symbolic system might represent:

    Socrates is a human
    All humans are mortal
    Therefore: Socrates is mortal

It typically relies on tools such as logic, knowledge graphs, expert-system rules, planning algorithms, and search.

Compared with neural-network AI, symbolic AI is usually:

    More interpretable: it can often explain which rules led to a conclusion.
    Good at structured reasoning: especially mathematics, planning, diagnosis, and rule-based decisions.
    Data-efficient: it can work from explicitly provided rules rather than requiring huge datasets.
    Less flexible with ambiguity: it may struggle with messy, incomplete, or uncertain real-world information.
    More labor-intensive to build: people often need to define the rules and concepts manually.

Modern systems sometimes combine both approaches. This is called neuro-symbolic
AI: neural networks handle perception and pattern recognition, while symbolic
methods support reasoning, planning, or verification.
